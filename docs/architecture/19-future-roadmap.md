# Future Roadmap

## Phase 1

Allowed after beta core loop is stable:

- live entitlement provider adapter;
- PDF vet report/export;
- weekly digest email;
- multi-pet/foster;
- better shareable puppy cards;
- weight tracking and symptom notes;
- referrals;
- dark mode/tablet if product evidence supports it;
- Storybook if component inventory outgrows `_dev/components`.

## Phase 2

Only after measured need:

- AI Q&A/coach with safety boundaries;
- breed-specific training plans;
- junior dog mode;
- insurance/commerce pilots with explicit labeling;
- richer offline-first sync if beta data shows frequent failed logging.

## Revisit Triggers

Reopen architecture if:

- Quick Log failed-save rate remains high;
- users need durable offline beyond Quick Log;
- trainer sharing creates privacy confusion;
- RLS performance degrades on timeline queries;
- notification delivery/reliability blocks retention;
- beta users strongly require multi-pet/foster workflows.
